## Waterfy 💧
![Static Badge](https://img.shields.io/badge/swift-6.4-orange?link=https%3A%2F%2Fwww.swift.org%2Fswift-evolution%2F%23%3Fversion%3D6.4)  

Waterfy is an Apple Watch App that allows to track the amount of ml that you have taken on that day. This app was made more for the acknowledgement of SwiftUI on Apple Watch and wanting to create something for my own enjoyment.

## 🗂️ Folder Structure

This workspace contains three folders, where:

- `Waterfy Watch App`: the folder to maintain sources
- `Assets.xcassets`: the folder to maintain app assets

> The design is very minimalistic and provides 0 need to pay for subscriptions or anything unoridinary for something so simple.
